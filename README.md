# Assignment 5 — JavaScript Basics

Nine separate pages cover JavaScript values and operators, DOM manipulation, events, a four-operation calculator, and an interactive to-do list. The site is written in plain HTML, CSS, and JavaScript.

**Student:** Ramin Smagulov · SE-2529  
**Live site:** [ramin293.github.io/web_assignment5](https://ramin293.github.io/web_assignment5/)

## Run locally

Open `index.html` in a browser. No installation or build step is needed. Use the navigation bar to move between Task 0 through Task 8. For Tasks 0 and 1, open the browser developer console to inspect the logged output.

## Tasks

| Page | Exercise |
| --- | --- |
| Task 0 | External script, `console.log()` and an alert |
| Task 1 | Strings, numbers, booleans, arithmetic and concatenation |
| Task 2 | Change paragraph content on click |
| Task 3 | Change a block's color and font size |
| Task 4 | Add and remove list elements |
| Task 5 | `mouseover` and `mouseout` events |
| Task 6 | Live text using `keyup` |
| Task 7 | Addition, subtraction, multiplication and division |
| Task 8 | Add, complete and delete tasks |

The to-do list is stored in a JavaScript array during the current page visit. Reloading the page clears it, as requested in the assignment. The task description field is optional.

## Publishing

GitHub Pages publishes the repository's `main` branch from its root folder. Because all links are relative, the pages work both locally and at the project URL above.

The original instructions are retained in `source_assignment5.docx`.
